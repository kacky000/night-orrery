Night Orrery is a plan-then-execute museum heist for the desktop browser. Plot Wren's route through the Halvard Museum (three preset ways in, or click your own), buy tools out of the take (smoke, camera loops, radio decoys, door overrides), then watch the plan run past sweeping cameras and patrolling guards' vision cones. Take over with WASD at any moment, sneak through the shadows, steal the Tidewater Astrolabe and get it back to the van.

Controls: click the map to add waypoints (right-click removes one), A/B/C pick a preset route, Space runs the plan. During the run: WASD move, Shift sneak, E pick a lock, F rejoin the route, 1-4 arm a tool then click the map. R returns to the plan after a getaway or a lockdown.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
